DACS Project Report LaTeX Template

Files
-----
report.tex
    Main report template using the IEEEtran conference format.

references.bib
    BibTeX database for scientific references.

How to use
----------
1. Keep report.tex and references.bib in the same folder.
2. Add your project title and student names in report.tex.
3. Replace the guidance comments (%) with your own report content.
4. Add references to references.bib.
5. Cite sources in the report using \cite{referenceKey}.
6. Compile with LaTeX/BibTeX, or upload both files to Overleaf.

Important
---------
The comments in report.tex are guidance only and should not appear as report text.
Students may adapt the section structure when this is justified by the project,
while keeping the report coherent and scientifically structured.
