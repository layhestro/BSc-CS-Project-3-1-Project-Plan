\subsection{Societal impact}
\secinfo{Jimena}{dddd}
The use of FHE requires a deep, specialized understanding of both cryptography and hardware architecture. By evaluating a compiler that decouples application logic from hardware accelerators, our project shows how developers can implement advanced encryption without the need to be cryptographers. Finally, sine standard cloud processing requires data to be decrypted in memory, which makes it vulnerable, the use of HEIR moves us (and the company) to a zero-trust model where even cloud providers or malicious insiders cannot access the plain text data during computation.
Currently, theirs a lot of public awareness of data harvesting and unauthorized data brokering has severely eroded thrust in single sign-on services, as users fear their personal networks are being exploited or sold. If Fully Homomorphic encryption becomes highly efficient through compilers like HEIR, it solves this trust deficit from the users. 

\subsection{Economic impact}
\secinfo{Jimena}{dddddd}
FHE is really resource-intensive, so the systematic benchmarking of sorting and shuffling algorithms across CPUs will provide business with comprehensible metrics on running costs. Also, writing custom hardware-specific code optimizations is highly expensive, specially for encrypted operations. If HEIR allows developers to write code once and running it anywhere, it  decreases the cost required to deploy encrypted workloads and a reduction of software development time.
